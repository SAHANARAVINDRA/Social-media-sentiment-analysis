About This Project

This project is a Social Media Sentiment Analysis System that analyzes user opinions from posts, comments, and text inputs.

📊 What it does

The system classifies content into:
😊 Positive
😐 Neutral
😢 Negative

⚙️ Technologies Used

Backend: Python, Flask
Frontend: HTML, CSS, JavaScript
Libraries: VADER Sentiment Analyzer, Scikit-learn

🚀 Features

✔ Analyze text sentiment
✔ Instagram post preview
✔ Image text extraction (OCR)
✔ Dashboard with insights

🎯 Goal

To help users understand public opinion and trends from social media data using AI-based sentiment analysis.
